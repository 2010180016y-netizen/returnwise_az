## 2. 재해복구(DR) 및 백업 지속가능성

1. **데이터 무손실 복구 (RPO < 1시간)**:
   - Cloudflare D1 자동 백업 및 `caseService.restoreTenantCases` JSON 스냅샷 복원 기능 완비.
   - 격리 검증: 타 테넌트 백업 스냅샷 침범 시도 즉시 `403 Forbidden` 차단.
2. **긴급 롤백(RTO < 10초)**:
   - 프로덕션 장애 발생 시 Cloudflare Pages 원클릭 롤백 기준점(`f812c4e9fa6ae0c08b8420ad611052a2b970bcd2`) 즉시 기동.

## 4. 고객 지원(CS) 및 악용 방어 체계

1. **단위 고객당 CS 비용 통제**:
   - 예상 CS 소요 시간: 건당 15분 이내.
   - FAQ 9종, 상세 1원 산식 unfold, 전자상거래법 법적 근거 원클릭 복사 기능으로 셀러 자체 해결률 80% 이상 유도.
2. **악성 파일 및 어뷰징 방어**:
   - DDE 스프레드시트 수식 주입(`=, +, -, @`) 작은따옴표 중화 처리.
   - 단일 파일 5MB / 1,000행 초과 시 즉각 차단.
   - 무료 사용자 Pro 기능 접근 시 서버측 `403 PRO_PLAN_REQUIRED` 차단.
   - Starter 사용자 월 100건 초과 시 `429 QUOTA_EXCEEDED` 차단.

## 5. 최종 운영 지속가능성 결론

- **결론**: **ReturnWise Pro는 월 고정비 $0의 완전 무과금 서버리스 아키텍처 위에서 단위당 공헌이익 86.7%를 보존하며 안정적으로 운영 가능함.**
- **안전 준수**: "수익 자동 발생"이나 "운영 무인화"를 주장하지 않으며, 대표님의 명시적 승인 후 선별 셀러 5인 클로즈드 베타부터 단계적으로 확장함.
