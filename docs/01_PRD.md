# 01. 제품 요구사항 정의서 (PRD)

## 한 줄 가치제안
한국 소규모 판매자가 고객에게 약속된 권리와 플랫폼 규칙을 존중하면서, **허용된 반품 처리 방식**의 추가 지출 및 순경제적 비용을 빠르고 투명하게 비교하는 브라우저 기반 계산기.

## 사용자·사용 시나리오
- 우선 사용자: 1~5인 온라인 판매 사업자 또는 CS 담당자. 반품 문의가 들어왔고 판매가·회수비·검수비는 알지만 회수 후 가치가 불확실하다.
- JTBD: '이번 반품 처리에 얼마가 더 드는지', '회수하는 것과 회수하지 않는 것의 경제적 차이'를 계산하고 동료/거래처에 설명한다.
- 빈도는 가설. 초기 인터뷰로 수치 검증할 것.

## North-star / 가드레일
- 핵심 지표: 유효 계산을 완료한 사용자 중 7일/30일 이내 자발적으로 다시 계산한 비율(추적 방식은 개인정보 검토 후 결정; 초기에는 패널 인터뷰/자가보고 활용).
- 선행 지표: 계산 시작→완료 비율, 복사 클릭, 재방문 동기, 계산 시간 절감의 인터뷰 평가.
- 안전 지표: 잘못된 수학적 결과 0건; 비허용 옵션이 추천으로 표시된 0건; PII 수집 0건; 법적 보장 오해 문구 0건.

## 무료 MVP 기능
- [P0] 단일 반응형 페이지, 처리 건별 정보 입력, KRW 정수 계산, 입력 검증.
- [P0] 기본 대안: 전액환급+회수, 회수 없는 전액환급; 이용자 확인을 통과한 경우에 한하여 고객 합의 부분환급; 교환은 별도 비교 그룹.
- [P0] 두 지표(추가 현금지출/순경제적 처리비용)와 산식·가정·누락 비용 공개.
- [P0] 정책/권리 관련 질문 체크 + `확인 필요/비교 제외` 상태.
- [P0] URL 공유에 민감한 수치를 넣지 않는 복사 기능(클립보드 복사만).
- [P0] 개인 기기의 운송비·검수비 기본값만 저장(개별 반품 입력 전체/상세는 기본 저장하지 않음).
- [P0] 입력 초기화, 예시 불러오기, FAQ, 법률적 유의사항, 개인정보·운영자 정보.
- [P0] Mobile/keyboard/스크린리더 지원, 오류 피드백, 기본 SEO.

## MVP 비범위
계정·로그인·DB·결제·추천 AI·주문번호/주소/전화번호 입력·이메일 발송·마켓 API 연동·실제 환불 수행·법률적 권리 자동 확정·자동 가격 크롤링·자동 CSV 업로드·백오피스.

## 조건부 Pro
월간 이력/다건 CSV 처리/통계/회사계정/안전한 정기결제/서비스 운영 대시보드. 수요 검증(G5) 후 착수.

## 전제 및 의사결정 기록
- '최저비용'은 원가가 아니라 **현재 고객과 판매자가 적법하게 선택할 수 있는 처리 방법 사이의 추가 처리비용** 기준.
- '부분 환급'은 자동적으로 판매자가 선택할 수 있는 수단이 아님. 합법·적법·자발적 합의와 플랫폼 절차가 확인된 경우에만 비교 옵션.
- 수익, 방문자, 검색량, 전환율, 구독가격은 검증 전에는 모두 가설.

## 성공 조건과 피봇 조건
- G4: 최소 18개의 핵심 계산 fixture와 8개의 안전 게이트 시나리오 모두 PASS, 브라우저 자동 E2E PASS, 외부 개인정보 송신 0건, 사용자 테스트 확인.
- G5: 실 사용자 15~20명 관찰/인터뷰; 30+ 유효 사용자(중복 없는 참여자 자체 확보 기준), 반복 업무 활용 사례 최소 5건, Pro 지불 의사 최소 5명(구체적인 금액과 구매 시점 명시). 통계적 확증 아님.
- 미달 시: 문제 재정의 또는 무료 리드 제휴로 재설계. 검증 없이 개발비 확대 금지.
