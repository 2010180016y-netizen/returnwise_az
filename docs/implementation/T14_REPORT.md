## 4. 계산 / 법률 / 시각화 가드레일 검증
1. **가상 예시 C01 vs C02 동시 표시 실측:**
   - 회수 후 전액환급(C01): 현금 지출 34,500원 / 순경제비용 25,500원
   - 회수 없는 전액환급(C02): 현금 지출 30,000원 / 순경제비용 30,000원
   - 대조표에서 두 수치가 왜곡 없이 동시에 정수 KRW 단위로 표시됨을 통합 테스트로 확인.
2. **최소 비용 추천 배지 및 차액(Delta) 가드레일:**
   - 적격 대안이 2개 이상일 때만 1위에 `[최저비용 추천 (1위)]` 녹색 배지 부여.
   - 차상위 대안들에 `+1위 대비 X원 추가 지출` 차액 및 기준안 대비 절감 가능액 명확히 표기.
3. **비허용 대안(KEEP_PARTIAL 등) 안전 가드레일:**
   - 소비자 자발적 합의가 미확인된 경우 `INELIGIBLE` 상태로 추천에서 원천 배제(L03).
   - 카드와 표 모두에서 회색 음영 및 점선 처리, `[추천 제외]` 배지와 구체적 차단 사유 노출.
4. **특별 안전조건(`수익/확정절감` 오인 문구 금지) 100% 준수:**
   - 판매자에게 손실이 발생하는 반품 상황에서 '수익'이나 '확정 절감'이라는 표현을 일체 배제.
   - '손실 절감 가능액', '추가 지출 차액' 등 보수적이고 객관적인 재무 표현만 사용.
5. **순경제비용 음수 해석 안내:**
   - 회수 상품 순가치가 총 지출을 초과하여 음수 발생 시 `(회수 자산 가치가 지출을 초과하여 회수 이득 발생)` 안내문 표시.
6. **모바일 가로 스크롤 방지:**
   - 320px 모바일 화면에서는 1열 세로 스택 그리드, 테이블 영역은 `overflowX: 'auto'` 컨테이너로 감싸 페이지 전체 가로 스크롤 방지.
