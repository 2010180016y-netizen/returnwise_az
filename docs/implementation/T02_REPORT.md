## 4. 계산 / 법률 / 보안 가드레일 검증
1. **출처 없는 허용 판정 0건 검증:** 국가법령정보센터 조문(제17조, 제18조, 제19조, 제35조)과 공식 마켓 약관에 근거가 없는 '적법함' 단정을 원천 차단하고, 미확인 마켓/약관은 `UNKNOWN`으로 규정함.
2. **소비자보호 Fail-closed 게이트:** 소비자 자발적 합의, 마켓 정책 허용, 법적 권리 비침해의 3가지가 모두 True로 입증되지 않으면 `KEEP_PARTIAL`(부분환불) 대안을 추천 후보에서 완전히 제외하도록 매트릭스를 확립함.
3. **판매자 귀책 운임 전가 차단:** 판매자 귀책(`SELLER_FAULT`, `DEFECT_OR_DIFF`) 시 고객에게 배송비를 전가하는 계산은 입력 레벨에서 차단(L02)하도록 명시함.
4. **특별 안전조건:** 법률 전문가의 검토 없이 적법성을 시스템이 확정하지 않으며, "입력 조건에 따른 추정 비용 시뮬레이션"으로 카피 가드레일을 통제함.
