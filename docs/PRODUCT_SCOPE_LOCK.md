## 1. 제품 개요 및 핵심 가치제안

### 1.1 한 줄 가치제안
한국의 1~5인 소규모 온라인 커머스 판매자가 고객에게 약속된 법적 권리와 마켓 규정을 침해하지 않으면서, **허용된 반품·환불·교환 처리 방식의 추가 현금 지출과 순경제적 비용을 30초 내에 투명하게 비교**할 수 있는 반응형 1페이지 무료 계산기.

### 1.2 핵심 문제 정의
- 판매자는 반품 요청 시 '얼마나 돌려줘야 하고, 운송비·검수비로 추가 얼마가 지출되는지', '반품을 회수하는 것과 회수하지 않고 폐기/선물하는 것 중 어느 쪽이 경제적으로 덜 손해인지'를 즉시 판단하기 어렵다.
- 기존의 단순 마진 계산기는 고객 동의 없는 부분환불을 일방적으로 추천하거나, 비현금 자산인 '회수 상품가치'를 현금 지출에서 임의 차감하여 판매자에게 자금 유동성 착시를 유발한다.

## 2. 사용자 페르소나 및 JTBD (Jobs To Be Done)

### 2.1 우선 사용자 페르소나
- **대상:** 네이버 스마트스토어, 쿠팡, 자사몰을 운영하는 1~5인 온라인 판매자 및 1인 셀러/CS 담당자.
- **상황:** 고객으로부터 단순변심 또는 제품 불만 반품/교환 문의를 접수했으며, 판매가와 배송비는 알지만 회수 시 추가 손실액 계산이 막막한 상태.
- **동기:** 법적 분쟁 위험 없이 가장 손실이 적은 처리 방식을 빠르게 계산해 팀원/동료와 공유하고 처리 결정을 내리고자 함.

### 2.2 JTBD 정의

> 위법한 처리나 자금 유동성 왜곡 없이 각 선택지별 추가 현금지출과 순경제적 손실을 1원 단위로 정확히 대조하여 (Motivation),  
> 이번 건의 최적 처리 방식을 확신을 갖고 결정하고 분쟁을 예방하고 싶다 (Expected Outcome)."

## 3. 1페이지 사용자 동선 (Single Page Flow)

```
[Header] 로고(ReturnWise) · 사용 가이드 · FAQ · 법률/면책 고지
   ↓
[Hero] "반품 한 건, 실제로 얼마가 더 들까요?" (가입 없음 · 100% 브라우저 계산)
   ↓
[STEP 1: 상황 및 권리 확인]
  - 고객 요청 (환불 / 교환 / 미확인)
  - 반품 사유 (단순변심 / 판매자 귀책 / 표시광고 상이 / 미확인)
  - 판매 마켓 (스마트스토어 / 쿠팡 / 자사몰 / 기타)
  - 법적 권리 및 마켓 규정 확인 체크박스 (미확인 시 대안 추천 차단)
   ↓
[STEP 2: 금액 및 비용 입력 (KRW 원 단위)]
  - 환급 예정 금액 (원거래 배송비 포함 여부 표시)
  - 판매자 부담 회수 운송비 (고객부담분 재합산 금지)
  - 처리/검수/재포장비
  - 회수 상품의 보수적 순가치 (처분/재판매 가능 순가치)
  - 확정 수수료 환급액 (미확인 시 0원)
  - 기타 해당 방식 고유 비용
   ↓
[STEP 3: 대안 비교 선택 (4대 선택지)]
  - [대안 1] 회수 후 전액환급 (기준 대안)
  - [대안 2] 회수 없는 전액환급
  - [대안 3] 합의된 부분환급 (소비자 자발적 합의 + 플랫폼 허용 확인 필수)
  - [대안 4] 1:1 교환 처리 (교환 요청 또는 동의 확인 필수)
   ↓
[Result: 비용 비교표 및 시각화]
  - 두 지표 엄격 분리: ① 추가 현금지출(cashOutflow) vs ② 순경제적 처리비용(economicCost)
  - 부적격/미확인 대안은 회색 비활성화 및 '확인 필요' 상태 표시
   ↓
[Breakdown: 상세 산식 설명]
  - 1원 단위 산식 분해, 적용된 가정, 누락 가능 비용 경고
   ↓
[Actions: 유틸리티]
  - 클립보드 결과 복사 (URL 파라미터 삽입 금지)
  - 기본값 초기화 / 예시 데이터 불러오기
  - 내 기본비용(운송비/검수비) 브라우저 로컬 저장 (사용자 명시 체크 시)
   ↓
[FAQ / Notice / Footer]
  - 자주 묻는 질문 4종, 전자상거래법 관련 유의사항, 면책 고지, 운영자 정보
```

## 5. 명시적 비범위 (Out-of-Scope: 절대 개발 금지)

다음 항목은 무료 MVP 범위에서 **완전히 배제(Out-of-Scope)**하며, 코드나 패키지를 일체 추가하지 않는다:
1. **서버 및 데이터베이스:** Node 백엔드, DB(PostgreSQL/MySQL/MongoDB/Supabase/Firebase), ORM 일체 미사용.
2. **회원가입 및 인증:** 로그인, JWT, OAuth, 세션, 계정 관리 일체 없음.
3. **결제 및 PG 연동:** 토스페이먼츠, 스트라이프, 나이스페이 등 PG 모듈 및 정기결제 일체 미사용.
4. **개인식별정보(PII) 입력:** 고객명, 주문번호, 송장번호, 전화번호, 배송지 주소 등 PII 입력 필드 원천 배제.
5. **마켓 API 및 외부 크롤링:** 스마트스토어/쿠팡/11번가 API 연동, 실시간 배송비/수수료 크롤링 없음 (사용자 수동 입력 원칙).
6. **AI API 호출:** OpenAI, Claude, Perplexity 등 외부 AI LLM API 호출 없음 (규칙 기반 순수 함수 엔진).
7. **자동 환불/처리 집행:** 실제 커머스 마켓 환불 처리 대행 기능 없음.
8. **다건 CSV 대량 분석:** CSV 업로드 파싱 기능 없음 (1건씩 단일 계산).

## 7. 핵심 성공 지표(KPI) 및 실패/피봇 기준

### 7.1 성공 지표
1. **품질/안전 지표:**
   - 18개 계산 fixture + 8개 안전 게이트 100% 통과 (0 error).
   - 비허용 대안의 최저비용 오인 추천 0건.
   - PII 유출 및 외부 네트워크 전송 0건.
2. **사용성 지표:**
   - 계산 완료율 70% 이상 (정상 입력 도달 비율).
   - 결과 복사 클릭률 20% 이상.
   - 재방문 인터뷰 만족도 80% 이상.

### 7.2 실패 및 피봇 기준
- G4 출시 후 90일 내 실사용자 15명 인터뷰 중 "실제 업무 결정에 도움이 되지 않는다"는 응답이 50% 이상일 경우.
- Pro 지불 의사(월 9,900원~19,900원)를 표명한 판매자가 5명 미만일 경우.
- **피봇 방향:** 유료 SaaS 확장을 영구 중단하고, 무료 리드 수집용 제휴(세무/포장재/택배 제휴) 모델로 전환하거나 기능을 재정의함.

## 8. 불확실성, 가정 및 잔여 리스크

1. **[가정]** 소규모 판매자는 반품 1건당 평균 3,000~5,000원의 회수 운송비와 상품 폐기 여부를 수동으로 고민하고 있을 것이다 (G5 인터뷰로 실측 필요).
2. **[법률 리스크]** 2026-07-21 시행 개정 전자상거래법의 세부 분쟁 조정 기준에 따라 마켓별 단순변심 배송비 부담 기준이 상이할 수 있음 → T02에서 공식 법령 및 주요 3대 마켓 약관 대조 매트릭스로 완화.
3. **[수익화 리스크]** 1페이지 단일 계산기는 편리하지만 '유료 구독'으로 이어지기에는 지불 가치가 약할 수 있음 → 무료 MVP로 트래픽 및 판매자 신뢰를 확보한 후 다건 일괄 처리(CSV) 수요를 철저히 검증하여 진행.
