## 1. 결제 연동 배경 및 특별 안전조건 엄수

1. **배경**:
   ReturnWise Pro는 월 50건 이상의 반품을 처리하는 셀러를 위한 정기 구독(월 9,900원 ~ 14,900원) 모델을 지원한다.
   원화 결제, 세금계산서/현금영수증 발행, 국내 신용카드 간편결제를 안전하게 처리하기 위해 국내 전자결제대행사(PG)를 비교 평가하고 정기결제 연동 방식을 확정한다.

2. **특별 안전조건 1: 직접 카드정보 수집 및 저장 절대 금지 (Zero-PCI Risk)**:
   > **경고**: ReturnWise 서버는 고객의 신용카드 번호, 유효기간, CVC, 비밀번호를 수집하거나 저장하지 않습니다.
   > 모든 결제 수단 입력은 토스페이먼츠의 보안 호스팅 결제창(Checkout)에 100% 위임하며, 서버에는 토큰화된 빌링키(`billingKey`)만 안전하게 전달됩니다.

3. **특별 안전조건 2: 실계약 및 실제 카드 결제 자동 실행 금지**:
   > **경고**: AI 에이전트가 임의로 PG 가입 계약을 체결하거나 유료 결제를 자동으로 실행하는 것을 엄격히 금지합니다.
   > 모든 비용 지출과 계약 서명은 결재자(김회기 대표님)의 명시적 승인 후 수동 집행됩니다 (현재 실 결제 요청 0건 실측).

## 3. 운영자 요건 및 법률/세무 컴플라이언스

1. **사업자 및 통신판매업 요건**:
   - 상호, 대표자명, 사업자등록번호, 통신판매업 신고번호 필수.
   - 전자상거래법 제10조 제1항에 따라 사이트 푸터에 모든 사업자 정보 노출 필수.
2. **환불 규정 및 청약철회 (전자상거래법 제17조 준수)**:
   - 디지털 정기구독 서비스로서 **결제일로부터 7일 이내에 서비스를 전혀 이용하지 않은 경우 100% 전액 환불**.
   - 7일 경과 후 또는 서비스 이용(CSV 계산 실행 등) 후 중도 해지 시 잔여 기간에 대해 **일할 계산 환불** 지원.
3. **세금 및 가격 표시 (부가세 10% 포함)**:
   - 가격 표시 왜곡을 방지하기 위해 모든 요금제 금액은 **부가가치세(VAT 10%)가 포함된 최종 결제 금액**으로 표기.
     - Starter: 월 9,900원 (공급가액 9,000원 + 부가세 900원)
     - Pro: 월 14,900원 (공급가액 13,545원 + 부가세 1,355원)

## 4. 토스페이먼츠 샌드박스(Sandbox) 테스트 계획

*실제 과금 없이 안전한 가상 환경에서 결제 라이프사이클을 100% 검증하기 위한 샌드박스 명세입니다.*

- **테스트 API 키**: `test_ck_...` (클라이언트 키), `test_sk_...` (시크릿 키)
- **가상 테스트 카드 시나리오**:
  1. **정상 결제 카드**: 빌링키 발급 성공 -> 정기결제 승인 (`200 OK`) -> `ACTIVE` 상태 전이.
  2. **잔액 부족 카드**: 결제 승인 실패 (`400 INSUFFICIENT_BALANCE`) -> `PAST_DUE` 전이 및 재시도 스케줄러 등록.
  3. **분실/도난 카드**: 결제 거절 (`400 REJECTED_CARD`) -> 즉각 결제 수단 변경 요청 안내.
- **실 결제 요청 관측치**: **0건 (Zero Real Transaction)** 입증.
