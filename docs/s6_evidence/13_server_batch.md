## 1. 무료 로컬 CSV vs Pro 서버 CSV 동의 및 보안 경계

| 구분 | 무료 MVP (로컬 CSV 미리보기) | Pro 플랜 (서버 CSV 일괄 처리) |
|:---|:---|:---|
| **처리 위치** | 브라우저 JS 런타임 메모리 (서버 미전송) | 격리된 Cloudflare Worker 백엔드 메모리 |
| **파일 전송** | 네트워크 전송 0건 (`fetch`/`xhr` 차단 실측) | HTTPS TLS 1.3 암호화 전송 + Bearer 인증 필수 |
| **PII 처리** | 고객명·주소 등 PII 열 탐지 시 화면 표시 배제 | 식별정보 미제거 시 수집 즉각 거부 및 메모리 파기 |
| **결과 저장** | 브라우저 탭 종료 시 자동 소멸 | 최소 요약 통계만 D1 보관 (원본 파일 저장 0건) |
| **약관 및 동의** | 기본 무료 이용약관 적용 | 유료 서비스 약관 + 데이터 위탁 처리 별도 동의 |

## 2. 보안 가드레일 및 쿼터 제한 실측

`tests/unit/csvBatch.test.ts`, `tests/s4/`, `tests/unit/quotaGuard.test.ts` 실측 결과:

1. **DDE 수식 주입 (CSV Formula Injection) 방어**:
   - `=cmd|`, `+`, `-`, `@`, `\t`, `\r`로 시작하는 악성 셀 값을 작은따옴표(`'`) 접두어로 자동 중화 (100% PASS).
2. **엄격한 파일 규격 및 PII 안전조건**:
   - 5MB 초과 파일 즉각 거부 (`FILE_TOO_LARGE`).
   - 1,000행 초과 시 즉각 거절 (`ROW_LIMIT_EXCEEDED`).
   - UTF-8 BOM 자동 처리 및 비-UTF-8 손상 바이트 파싱 거부.
3. **플랜별 사용량 쿼터 가드 (`quotaGuard.ts`)**:
   - 무료 플랜(FREE)의 배치 처리 요청 시 즉시 `403 Forbidden` (`PRO_PLAN_REQUIRED`) 차단.
   - Starter 플랜의 월 100건 한도 초과 시 과금 발생 없이 `429 Too Many Requests` (`MONTHLY_QUOTA_EXCEEDED`) 안전 차단.

## 3. 데이터 생명주기 및 파기 정책 (Data Lifecycle)

- **원본 CSV 파일 보관**: **0건 (Zero-Persistence of Raw Files)**.
- **계산 요약 결과 (Cases)**: 테넌트 격리 외래키 바인딩 하에 최대 365일 보관 후 영구 파기 스케줄.
- **소비자 삭제권**: `DELETE /v1/cases/:id` 호출 시 즉시 404 재조회 불능 파기.
- **고객 데이터 서버 보관 승인 상태**:
  - 실제 고객 주문 원본 데이터의 서버 수집에 대한 법률 승인 및 이용자 서면 동의 절차가 미완료 상태임.
