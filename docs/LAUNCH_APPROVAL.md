## 2. 법률·게시문구·운영자 표시 전수 확인 체크리스트

운영자 서명 전 필수 확인 항목입니다:

- [x] **2026 전자상거래법 출처 확인**: 제17조(청약철회), 제18조 제9항(단순변심 배송비), 제18조 제9항 단서(판매자 귀책 전가 금지), 제35조(소비자 불리 약정 무효) 법제처 원문 정합성 확인 완료.
- [x] **법률·세무 비자문 면책 고지 확인**: "변호사법 및 세무사법에 따른 자문이 아님"이 메인 화면과 푸터에 상시 노출됨을 확인 완료.
- [x] **개인정보 미수집 증빙 확인**: 입력 폼에 주문번호, 고객 성명, 연락처, 배송지 주소 등 PII 필드가 일체 없음을 확인 완료.
- [x] **운영자 정보 대외 고지 상태**: 정식 사업자 정보 입력 전까지 임의 법인명을 날조하지 않고 `[사람 승인 대기]` (`REVIEW_REQUIRED`) 상태로 안전하게 표시됨을 확인 완료.
- [x] **오인·기만 문구 배제 확인**: 판매자 손실 상황에서 "수익"이나 "확정 절감"이라는 오인 문구를 일체 배제하고 "추가 현금 지출", "순경제적 손실", "절감 가능액"으로 정직하게 표현함을 확인 완료.

## 3. 잔여 위험 및 운영 주의사항

1. **커스텀 도메인 DNS 연결**: 정식 도메인 연결 시 Cloudflare Pages SSL 인증서 자동 발급 후 정상 HTTPS 작동 여부 모니터링 필요.
2. **사업자 등록 정보 갱신**: 추후 정식 상호 및 사업자등록번호가 확정되면 `src/content/disclosures.ts`의 `OPERATOR_DISCLOSURE`를 갱신하고 `status: 'VERIFIED'`로 전환 권장.
