## 실행 원칙
- 티켓을 **한 번에 하나씩** 복사해 코딩 에이전트에 입력한다. 끝나면 보고서·테스트·리뷰 후 다음 단계.
- S6-01~08은 **무료 사이트 공개 전 필수 작업**, S6-09~16은 **유료 Pro에만 필요한 조건부 작업**.
- 아직 모든 개선 PR은 Draft 상태이고, 연결된 Cloudflare 계정 Pages/D1은 감사 당시 각각 0개였다. 시작할 때 재조회한다.
- 실제 서비스 공개·DB 생성·실결제·PR 병합 등은 사용자 개별 승인 없이는 실행하지 않는다.
- `npm run release:preflight`: 증빙 매니페스트의 정합성을 확인하고 **BLOCKED를 정직하게 출력하면 exit 0**.
  `npm run release:authorize:free`, `npm run release:authorize:pro`: 실제 승인 없을 때 **exit 2**가 정상.
- 문서상 예전 PASS/가짜 수익/합성 사용자 인터뷰를 외부 검증 증거로 받아들이지 않는다.
