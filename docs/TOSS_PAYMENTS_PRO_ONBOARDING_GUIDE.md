## 2. 토스페이먼츠 PG 가맹 계약 필수 구비 서류

전자결제(PG) 가맹점 계약은 전자상거래법 및 금융결제원 가이드라인에 따라 아래 서류가 반드시 필요합니다:

| 필수 서류 | 발급처 | 소요 시간 | 비고 |
|:---|:---|:---:|:---|
| **1. 사업자등록증 사본** | 홈택스 (국세청) | 즉시 | 개인사업자(일반/간이) 또는 법인 |
| **2. 통신판매업신고증 사본** | 정부24 / 시·군·구청 | 1~2일 | 호스팅 제공자: Cloudflare Pages |
| **3. 대표자 신분증 사본** | - | 즉시 | 주민등록증 또는 운전면허증 |
| **4. 대표자 명의 통장 사본** | 거래 은행 | 즉시 | 정산금 입금 계좌 |
| **5. 구매안전서비스 이용확인증** | 은행 또는 토스페이먼츠 | 즉시 | 통신판매업 신고 시 제출용 |

*가맹비: 프로모션 적용 시 등록비 면제 (통상 약 22만 원). 카드사 수수료: 일반 3.2%~3.4%, 영세/중소 우대 수수료율(1.5%~2.8%) 자동 적용.*

## 3. 토스페이먼츠 웹사이트 심사 5대 필수 기준 (체크리스트)

토스페이먼츠 및 카드사 심사관이 `https://returnwise-az.pages.dev`에 방문하여 아래 5개 항목을 전수 확인합니다:

- [ ] **1. 하단 푸터 사업자 정보 실체화**:
  - 상호명, 대표자명, 사업자등록번호, 통신판매업신고번호, 사업장 소재지, 고객센터 연락처(유선 또는 채널톡/이메일) 필수 표기.
  - *(현재 상태: `REVIEW_REQUIRED` 임시 대기 상태 -> 실제 사업자 정보 입력 필요)*
- [ ] **2. 법률 필수 문서 탑재**:
  - 서비스 이용약관 및 개인정보 처리방침 전문 열람 가능 여부 *(현재 초안 탑재 완료)*.
- [ ] **3. 디지털 재화 환불/청약철회 정책 명시**:
  - 결제 후 서비스 미이용 시 7일 이내 전액 환불.
  - 정기결제 해지 시 다음 결제 주기 자동 청구 중단 및 당월 잔여 일수 일할 환불 정책.
- [ ] **4. 유료 플랜 상품 설명 및 결제 금액 투명 고지**:
  - Starter 9,900원 / Pro 29,900원 VAT 포함 여부 명시.
- [ ] **5. 결제 모듈 정상 호출 여부**:
  - 토스페이먼츠 결제창 SDK(클라이언트) 및 서버 승인 웹훅 왕복 동작 확인.

## 4. 기술 연동 및 환경변수 주입 로드맵 (P01~P08)

토스 가맹 승인 완료 후 라이브 배포 절차:

1. **토스 개발자센터 상점 키 확인**:
   - `Client Key`: `live_ck_...` (프론트엔드 결제창 호출용)
   - `Secret Key`: `live_sk_...` (Worker 백엔드 서버 승인용)
2. **Cloudflare Worker & D1 환경변수 주입**:
   ```bash
   wrangler secret put TOSS_SECRET_KEY
   wrangler secret put TOSS_WEBHOOK_SECRET
   ```
3. **결제 모드 전환**:
   - `BILLING_MODE=live` 설정 시 S6-15 킬스위치 해제 및 정식 과금 가동.
4. **게이트 해제**:
   - P06 (실결제/취소/정산) `PASS` 전환, 회기님 최종 서명(`PENDING_OWNER_SIGN_OFF` -> `APPROVED`).
