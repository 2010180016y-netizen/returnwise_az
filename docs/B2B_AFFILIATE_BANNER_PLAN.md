# ReturnWise 무료 계산기 하단 B2B 제휴 배너 탑재 계획서

**문서 버전**: v1.0  
**작성일**: 2026-11-03  
**대상 서비스**: ReturnWise (https://returnwise-az.pages.dev)  
**목적**: 순수 무료 계산기 트래픽을 활용하여 $0 인프라 유지비 상태에서 즉각적인 실현 B2B 제휴 수익(CPS/CPA)을 창출하는 비침해적 네이티브 배너 시스템 설계 및 배포 로드맵.

---

## 1. 개요 및 비즈니스 배경

### 1.1 현재 문제 정의
- ReturnWise 무료 MVP는 $0 서버리스(Cloudflare Pages) 환경에서 완벽히 구동 중이나, 자체 결제 모듈(토스페이먼츠)이 아직 활성화되지 않아 트래픽이 발생해도 자체 과금 수익이 $0입니다.
- 반품 계산기를 사용하는 셀러는 **"반품 배송비와 재포장 검수비가 너무 많이 든다"**는 명확한 고통(High Intent Pain Point)을 체감한 직후 상태입니다.

### 1.2 솔루션: 고전환율 B2B 네이티브 제휴 슬롯
- 계산기 결과 섹션(STEP 3) 직후, 셀러의 비용 절감을 직접 돕는 **검증된 B2B 파트너 솔루션 3종**을 정보형 카드 형태로 배치합니다.
- 외부 추적기나 거부감을 주는 배너 광고 대신, 공정위 가이드라인을 준수한 정갈한 B2B 추천 카드로 설계합니다.

## 2. B2B 제휴 3대 핵심 카테고리 및 수익 구조

| 카테고리 | 타깃 문제의식 | 추천 파트너 예시 | 제휴 정산 방식 | 기대 객단가 (CPA/CPS) |
|:---|:---|:---|:---|:---|
| **1. 반품 전문 3PL / 검수 풀필먼트** | "반품 회수 후 검수·재포장 인건비가 부담스러움" | 품고(FMD), 파스토, 콜로세움, 리턴박스 | B2B 상담 신청 완료 또는 첫 계약 시 건당 정산 | **CPA 50,000원 ~ 100,000원 / 사** |
| **2. 반품 완충재 / 포장재 도매** | "에어캡, 테이프, 반품 단상자 소량 구매 단가가 높음" | 박스스토어, 패커, 방산시장 B2B 몰 | 전용 할인쿠폰 적용 구매액 비례 수수료 | **CPS 5% ~ 8%** (월 반복 결제) |
| **3. 쇼핑몰 통합관리 / 반품 자동화 솔루션** | "네이버·쿠팡 반품 분실/누락 관리가 수동이라 지침" | 사방넷, 플레이오토, 이지어드민 | SaaS 신규 셀러 가입 및 솔루션 유료 구독 시 | **첫 달 결제액의 20% ~ 30% 또는 CPA 30,000원** |

## 3. 기술 아키텍처 및 보안·법률 규정 준수

### 3.1 엄격한 CSP (`connect-src 'none'`) 보안 준수
- ReturnWise는 현재 일체의 외부 네트워크 연결을 차단하는 강력한 CSP 헤더를 운영 중입니다:
  ```http
  Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'none'; img-src 'self' data:; frame-ancestors 'none';
  ```
- **원칙**: 구글 애드센스 등 외부 서드파티 JS 스크립트 탑재는 CSP 위반 및 PII 유출 위험이 있으므로 **원천 배제**합니다.
- **구현 방식**: 
  1. 순수 React 정적 카드 컴포넌트 (`<B2BAffiliateBanner />`)
  2. Cloudflare Pages `dist/_redirects` 307 리다이렉트 라우팅 (예: `/partner/3pl` -> 외부 제휴사 링크)
  3. `rel="noopener noreferrer sponsored"` 필수 속성 결속

### 3.2 공정거래위원회 추천·보증 심사지침 준수
- 각 제휴 카드 상단에 명확한 식별 배지 표기:
  - `[경제적 대가 관계 안내] 본 배너는 파트너사 제휴 링크를 포함하고 있으며, 계약 체결 시 ReturnWise에 소정의 수수료가 지급될 수 있습니다.`
- 기만적 광고 배제, 실측 파트너스 ID 결속.

## 4. UI/UX 컴포넌트 설계 명세

### 4.1 배치 위치
```
[STEP 1: 상황 및 권리 확인]
       ↓
[STEP 2: 비용 및 금액 입력]
       ↓
[STEP 3: 대안 비교 결과 (ResultView)]
       ↓
⭐ [신규 B2B 제휴 배너: B2BAffiliateBanner] ⭐  <-- 셀러가 고비용을 확인한 직후 최적 노출
       ↓
[CSV 일괄 검증 미리보기 (LocalCsvPreview)]
       ↓
[자주 묻는 질문 (FAQ)]
       ↓
[법률 면책 및 운영자 고지]
```

### 4.2 컴포넌트 구조 프로토타입 (`B2BAffiliateBanner.tsx`)
- 컨테이너: 연한 슬레이트 보더, 화이트 배경, 모바일 1열 / 데스크톱 3열 CSS 그리드.
- 각 카드 구성요소:
  - 카테고리 배지 (`반품 3PL`, `포장재 특가`, `ERP 자동화`)
  - 파트너사 명칭 및 핵심 가치 제안 (예: "반품 검수 인건비 40% 절감", "셀러 전용 포장재 15% 할인")
  - CTA 버튼: "파트너 혜택 확인하기 →" (새 창 열기)

## 6. 단계별 실행 로드맵

1. **Step 1: 정적 배너 UI 컴포넌트 구현 및 빌드 검증** (금일 즉시 가능)
   - `B2BAffiliateBanner.tsx` 컴포넌트 작성
   - `CalculatorPage.tsx` STEP 3 직하단 결속
   - 단위 테스트 및 esbuild 프로덕션 빌드 무결성 확인
2. **Step 2: 제휴 파트너사 링크 확정 및 307 리다이렉트 결속**
   - 회기님 보유 제휴 계정 또는 공개 파트너십 링크 연결
   - `dist/_redirects`에 단축 경로 매핑
3. **Step 3: GitHub main 반영 및 Cloudflare Pages 무중단 자동 재배포**
   - git commit & push -> Pages 자동 배포 완료
