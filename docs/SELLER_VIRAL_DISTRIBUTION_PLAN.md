**문서 버전**: v1.0

**대상 서비스**: ReturnWise (https://returnwise-az.pages.dev)  
**핵심 원칙**: 허상 배제, 실측된 접속 수단, 계정 제재(활동정지/차단) 0% 안전 프로토콜, 정보성 가치 선제공 모델.

## 1. 개요 및 마케팅 전략 프레임워크

### 1.1 셀러 커뮤니티의 특성과 홍보성 글의 치명적 리스크
- 셀러 카페(스사모, 셀러오션 등)는 상업적 스팸에 극도로 민감하여, 단순 홍보성 링크나 바이럴 업자식 글은 **10분 내 삭제 및 영구 활동정지(활중)** 처리됩니다.
- **돌파구: '순수 무료 유틸리티 배포' (Giver Strategy)**
  - 상업적 홍보 글이 아니라, **"2026 개정 전자상거래법(반품비 전가 금지 강행규정) 때문에 반품 손익 계산 골치 아파서 직접 만든 무료 계산기 배포합니다"**라는 개발자 공유 글 형태로 접근합니다.
  - 가입/로그인 요구 0%, 결제 요구 0%, 개인정보 수집 0%인 순수 클라이언트 도구임을 전면에 내세워 관리자의 삭제 명분을 원천 차단합니다.

## 3. 채널별 맞춤 실전 배포 원고 팩

### [원고 A: 네이버 카페용 - 정보형 유틸리티 나눔]
- **제목**: [공유] 2026 개정 전자상거래법 시행 대비, 반품 건별 추가지출/순경제손실 30초 계산기 만들었습니다 (완전 무료/무가입)
- **핵심 본문 요약**:
  1. 최근 개정된 전자상거래법 제18조 제9항(판매자 귀책 반품비 전가 금지)과 제17조(부분환불 3대 합의 요건) 때문에 반품 건마다 마진 계산이 너무 복잡해졌음.
  2. 엑셀 수식 돌리다가 불편해서 1인 개발로 광고/로그인/서버 저장 일체 없는 $0 정적 웹 계산기를 제작함.
  3. 현금 추가지출 vs 순경제비용을 한눈에 비교해주고 슬랙/카톡 공유용 익명 리포트 복사 기능도 넣었음.
  4. 셀러 대표님들 피드백 주시면 기능 계속 보강하겠음. 링크: `https://returnwise-az.pages.dev`

### [원고 B: 디시 스스갤용 - 담백한 개발 후기형]
- **제목**: 반품 들어올 때마다 대가리 깨져서 반품 계산기 하나 파봤다
- **핵심 본문 요약**:
  - 단순변심인지 판매자 귀책인지 헷갈리고 부분환불 할지 회수할지 계산하기 귀찮아서
  - 현금 지출이랑 실제 순손실 대조해 주는 웹 계산기 하나 만듦.
  - 가입 없음 로그인 없음 광고 없음 그냥 즐겨찾기 박아두고 써라
  - 링크: `https://returnwise-az.pages.dev`

## 4. 유입 트래픽의 수익화 전환 흐름 (Funnel)

```
[커뮤니티 배포 글 (가치 선제공)]
         ↓
[ReturnWise 무료 계산기 접속 (무가입/무광고 호감도 극대화)]
         ↓
[STEP 1~3: 반품 비용 계산 완료 (High Intent Pain 체감)]
         ↓
┌────────────────────────────────────────────────────────┐
│ ① 하단 B2B 제휴 배너 클릭 (3PL / 포장재 / ERP 도입)   │ ──> [즉각 제휴 수수료 발생]
│ ② CSV 일괄 계산 욕구 발생 (Pro WTP 지불의향 확보)      │ ──> [토스 PG 구독 전환 대기]
└────────────────────────────────────────────────────────┘
```

## 5. 실행 체크리스트

1. **사전 준비**:
   - 네이버 카페(스사모, 셀러오션) 회기님 계정 등업 상태 확인 (필요 시 가벼운 댓글 3회 작성).
2. **배포 타이밍**:
   - 화~목요일 오전 10:00~11:30 또는 밤 21:00~23:00 (셀러 업무 피크 시간대 공략).
3. **모니터링**:
   - Cloudflare Pages 대시보드의 일간 방문자(Analytics) 및 배너 클릭률 추적.
