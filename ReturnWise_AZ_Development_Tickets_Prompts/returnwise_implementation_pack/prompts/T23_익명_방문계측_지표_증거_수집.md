# T23 | 익명 방문계측·지표 증거 수집

> G3 / 무료 MVP 또는 사업검증 단계
> 선행 조건: T21

## 개발 에이전트에게 붙여넣을 실행 프롬프트

너는 ReturnWise 프로젝트의 구현 책임자다. 먼저 저장소 상태와 `prompts/00_MASTER_PROMPT.md`, `START_HERE.md`, PRD/금융 산식/법률 게이트/기술 명세를 읽고 현재 티켓의 선행 조건 `T21` 완료 여부를 **실제 파일과 테스트로** 확인하라. 선행 조건 미충족이면 임의 보완·월권하지 말고 BLOCKED 보고서를 작성하라.

**현재 실행할 티켓은 T23 — 익명 방문계측·지표 증거 수집 하나뿐이다.**

**목적:** 최소한의 비용으로 방문 및 전환 가설을 검증한다.

**구체적 작업 지시:** Cloudflare Web Analytics 설정 가이드를 작성하고 승인 후 도입; WA는 custom event 미지원이므로 클릭/완료 자동 추적했다고 주장하지 않음; 초기 운영 대시보드 수동 템플릿 및 인터뷰 결과 집계; 새 event backend는 개인정보·비용·동의 검토 후 별도 ADR 필요.

**최소 산출물:** docs/ANALYTICS_SPEC.md, docs/METRIC_WEEKLY_TEMPLATE.md. 반드시 구현 및 테스트의 변경 파일 경로를 명시하고 `docs/implementation/T23_REPORT.md`를 남겨라.

**합격 판정기준:** 방문/검색/사용자 피드백의 측정 소스 구분; 이벤트 미측정은 미측정으로 표시; URL 개인정보 없음.

**특별 안전조건:** 개인 식별자·주문 데이터 분석도구 수집 금지.

실행 순서는 (1) 현 상태 확인 및 작은 실행계획 (2) 최소 변경 구현 (3) 명시한 판정기준의 테스트 작성·실행 (4) 반례·엣지케이스 검토 (5) 변경 파일/테스트 증빙 정리 (6) `PASS/CONDITIONAL/FAIL/BLOCKED` 판정이다. 실행하지 못한 명령은 `NOT_RUN`으로 남기고, 무단 결제/외부 공개/배포/원격 푸시 없이 종료하라. 범위 밖 발견사항은 다음 티켓 후보로 적어라.

**답변 형식:** `판정 → 실제 변경 파일 → 구현 핵심 → 실행한 테스트(명령·결과) → 미검증·잔여 위험 → 다음 티켓 진행 가능 여부`.
