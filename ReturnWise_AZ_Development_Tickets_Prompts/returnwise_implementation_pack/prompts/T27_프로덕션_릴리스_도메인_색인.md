# T27 | 프로덕션 릴리스·도메인·색인

> G4 / 무료 MVP 또는 사업검증 단계
> 선행 조건: T26

## 개발 에이전트에게 붙여넣을 실행 프롬프트

너는 ReturnWise 프로젝트의 구현 책임자다. 먼저 저장소 상태와 `prompts/00_MASTER_PROMPT.md`, `START_HERE.md`, PRD/금융 산식/법률 게이트/기술 명세를 읽고 현재 티켓의 선행 조건 `T26` 완료 여부를 **실제 파일과 테스트로** 확인하라. 선행 조건 미충족이면 임의 보완·월권하지 말고 BLOCKED 보고서를 작성하라.

**현재 실행할 티켓은 T27 — 프로덕션 릴리스·도메인·색인 하나뿐이다.**

**목적:** 명시 승인된 정적 사이트만 안전하게 공개한다.

**구체적 작업 지시:** G4 결과 확인; 사용자가 승인하면 main 보호/Cloudflare 배포/실제 URL/HTTPS/canonical/robots/sitemap 설정; Google Search Console 소유자 연동 및 제출은 승인과 계정 접근 시만; production smoke; 롤백 대상 기록; 공개 날짜 기록.

**최소 산출물:** docs/implementation/PROD_RELEASE.md, docs/ROLLBACK_POINT.md. 반드시 구현 및 테스트의 변경 파일 경로를 명시하고 `docs/implementation/T27_REPORT.md`를 남겨라.

**합격 판정기준:** 실 URL 접속 및 smoke PASS, HTTPS 정상, 권리 고지 표시; 접근 불가 시 배포 미실행 기록.

**특별 안전조건:** 승인 전 production push/배포/도메인 구매/검색 색인 제출 금지.

실행 순서는 (1) 현 상태 확인 및 작은 실행계획 (2) 최소 변경 구현 (3) 명시한 판정기준의 테스트 작성·실행 (4) 반례·엣지케이스 검토 (5) 변경 파일/테스트 증빙 정리 (6) `PASS/CONDITIONAL/FAIL/BLOCKED` 판정이다. 실행하지 못한 명령은 `NOT_RUN`으로 남기고, 무단 결제/외부 공개/배포/원격 푸시 없이 종료하라. 범위 밖 발견사항은 다음 티켓 후보로 적어라.

**답변 형식:** `판정 → 실제 변경 파일 → 구현 핵심 → 실행한 테스트(명령·결과) → 미검증·잔여 위험 → 다음 티켓 진행 가능 여부`.
