# T02 | 법률·마켓 정책 출처 등록 및 차단 매트릭스

> G0 / 무료 MVP 또는 사업검증 단계
> 선행 조건: T01

## 개발 에이전트에게 붙여넣을 실행 프롬프트

너는 ReturnWise 프로젝트의 구현 책임자다. 먼저 저장소 상태와 `prompts/00_MASTER_PROMPT.md`, `START_HERE.md`, PRD/금융 산식/법률 게이트/기술 명세를 읽고 현재 티켓의 선행 조건 `T01` 완료 여부를 **실제 파일과 테스트로** 확인하라. 선행 조건 미충족이면 임의 보완·월권하지 말고 BLOCKED 보고서를 작성하라.

**현재 실행할 티켓은 T02 — 법률·마켓 정책 출처 등록 및 차단 매트릭스 하나뿐이다.**

**목적:** 법적 권리와 비용 비교를 분리한 안전한 의사결정 게이트를 정의한다.

**구체적 작업 지시:** 공식 법령·생활법령 URL과 조회일/관련 조문을 등록; 단순변심/하자/오배송/계약 불일치, 책임주체, 환불/교환 요청을 매핑; 네이버·쿠팡·자사몰 각각 공식 최신 정책을 확인 가능한 경우만 출처 기재; 미확인은 UNKNOWN; 부분 환불/교환/회수 없는 환불 허용 조건을 보수적으로 설정; 법률 검토가 필요한 문구 목록을 만든다.

**최소 산출물:** docs/LEGAL_POLICY_REGISTER.md, docs/DECISION_GATE_MATRIX.md. 반드시 구현 및 테스트의 변경 파일 경로를 명시하고 `docs/implementation/T02_REPORT.md`를 남겨라.

**합격 판정기준:** 출처 없는 허용 판정 0건; 미확인 시 추천 차단 조건 정의; 법률 전문 검토 미완료는 확인 필요 상태.

**특별 안전조건:** 전문가 검토 없이 적법성을 확정하지 말 것.

실행 순서는 (1) 현 상태 확인 및 작은 실행계획 (2) 최소 변경 구현 (3) 명시한 판정기준의 테스트 작성·실행 (4) 반례·엣지케이스 검토 (5) 변경 파일/테스트 증빙 정리 (6) `PASS/CONDITIONAL/FAIL/BLOCKED` 판정이다. 실행하지 못한 명령은 `NOT_RUN`으로 남기고, 무단 결제/외부 공개/배포/원격 푸시 없이 종료하라. 범위 밖 발견사항은 다음 티켓 후보로 적어라.

**답변 형식:** `판정 → 실제 변경 파일 → 구현 핵심 → 실행한 테스트(명령·결과) → 미검증·잔여 위험 → 다음 티켓 진행 가능 여부`.
