# 11. MVP 한국어 핵심 카피·에러 문구 예시

> 게시 전에 최종 운영 주체·법률 문구 검토 필수.

- H1: `반품 한 건, 얼마가 더 들까요?`
- Sub: `회수 배송비·검수비·상품 회수가치를 입력하면 처리 방법별 비용을 비교합니다.`
- Supporting: `무료 · 가입 없이 사용 · 계산은 이 브라우저에서 처리`
- Primary section: `1. 고객 요청과 처리 조건` / `2. 비용 입력` / `3. 예상 비용 비교`
- Input help, 환급액: `고객에게 실제 돌려줄 총금액입니다. 원배송비 환급을 포함하는 경우 함께 입력하세요.`
- Input help, 회수비: `고객 부담분이 아니라 판매자가 실제로 부담하는 추가 회수 운송비입니다.`
- Input help, 회수가치: `반품된 물건을 실제로 재판매·활용하여 회수할 수 있는 순가치입니다. 불명확하면 보수적으로 0원으로 계산하세요.`
- Input help, 수수료 환급: `마켓/결제사에서 취소 후 실제 회수되는 것이 확인된 금액만 입력하세요.`
- Output label: `추가 현금지출` / `순경제적 처리비용`
- Result safe: `입력된 조건에 따른 비용 추정치입니다. 법적 허용 여부를 판단하지 않습니다.`
- Incomplete: `비교에 필요한 항목을 확인해 주세요.`
- Unsafe: `정책·고객 동의 조건이 확인되지 않아 최저비용 대안 선정에서 제외했습니다.`
- Partial refund: `고객의 자발적 동의와 적법성, 판매 플랫폼의 처리 기준이 모두 확인된 경우에만 비용 비교에 포함합니다.`
- Exchange: `고객이 교환을 요청하거나 적법하게 동의한 경우에만 비교합니다.`
- Copy success: `비용 요약을 복사했어요.`
- Copy error: `복사가 제한되어 있어요. 아래 내용을 직접 선택해 복사하세요.`
- Local data: `내 기본 운송비·검수비를 이 브라우저에만 저장합니다. 반품 금액과 고객 정보는 저장하지 않습니다.`
- Footer caution: `법령과 쇼핑몰/마켓 정책, 실제 계약 및 비용 조건을 확인하세요. 본 사이트는 법률 자문 또는 자동 환불 처리 서비스를 제공하지 않습니다.`
